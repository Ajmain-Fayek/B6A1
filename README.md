# What are some differences between interfaces and types in TypeScript? 

ঊত্তরঃ টাইপ এনং ইন্টারফেস এর মধ্যে কিছু কমপারিজন টেবিল আকারে নিচে বর্ননা করা হলঃ

| টাইপ ( type ) | ইন্টারফেস ( interface ) |
| :--- | :--- |
| ১. ব্যবহার করা হয় কাস্টম টাইপ অ্যালাইস লিখতে। যেমনঃ প্রিমিটিভ, ইউনিয়ন, অব্জেক্ট, ফাংশন, টুপল এবং লিটারেল টাইপ্স। | ১. ব্যবহার করা হয় ফাংশন এবং অব্জেক্ট এর গঠন তৈরি করতে। |
| ২. এক্সটেন্ড করা যায় ইন্টারসেকশন ( & ) ব্যবহার করে | ২. এক্সটেন্ড করা যায় ( extends ) কিয়ার্ড ব্যবহার করে এবং নতুন প্রপার্টি সংযুক্ত করা যায়। |
| ৩. প্রতিবার ব্যবহারের সময় ইন্টারসেকশন টাইপ পুনর্মূল্যায়ন করে | ৩. টাইপস্ক্রিপ্ট এক্সটেন্ডেড ইন্টারফেস গুলো ক্যাস করে রাখে তাদের নাম দিয়ে, দ্রুত লুকাপ করার জন্য। |
| ৪. একই নামের টাইপ (ডিক্লারেশন মারজিং) সাপোর্ট করে না | ৪. ডিক্লারেশন মারজিং সাপোর্ট করে। এর মানে, আমরা একই নামের একাধিক ইন্টারফেস তৈরি করতে পারবো এবং টাইপস্ক্রিপ্ট সেগুলোকে মার্জ করে একটি সিংগেল ইউনিট হিসেবে দেখাবে। |
